# css-basics

Практика по CSS: селекторы, псевдоклассы, псевдоэлементы.

## Что использовал
- HTML: параграфы, ссылки, поле ввода, div
- CSS: селекторы по тегу, классу, id; вложенные селекторы
- Псевдоклассы: `:hover`, `:visited`, `:focus`, `:not`, `:empty`
- Псевдоэлементы: `::before`, `::after`, `::first-letter`, `::first-line`
- Порядок: `:first-of-type`, `:last-of-type`

## Чему научился
- Работать с приоритетами (класс сильнее тега, id сильнее класса)
- Менять цвета и убирать подчёркивание у ссылок
- Добавлять контент через `::before` и `::after`
- Скрывать пустые элементы
